What can AbiPaint do?

01 / SIZE

Resize images

Resize photos, adjust pixels and resolution, and set the canvas width and height.

02 / ADJUST

Image adjustments

Adjust exposure, contrast, saturation, vibrancy and opacity.

03 / MATERIALS

Brush, eraser, shape and text materials

Add brush, shape and text materials. The eraser removes brush marks or directly erases pixels from a selected image.

04 / EXPORT

Export image and working files

Export PNG, JPG or PDF. Desktop users can retain multiple automatically saved working files.

05 / REMOVE BG

Subject background removal

Quickly turn the background behind people, pets, objects, logos, or profile pictures transparent.

How to use AbiPaint

1. Import an image or set canvas size

Use Import image to add a photo, or set the width and height in Canvas size, then Apply resolution.

2. Use tools and materials

Choose Brushes, Eraser, Shapes, Text, Outline, Crop or Remove background as needed. With no image selected, Eraser removes brush marks; with an image selected, it directly erases pixels from that image. Background removal works best with logos, profile pictures, and photos with simple backgrounds. Selected materials can be moved, resized, rotated, duplicated, deleted and reordered.

3. Export image

Choose PNG, JPG or PDF from Export image. PNG is useful for transparent backgrounds, JPG for everyday sharing and PDF for documents.

What is AbiPaint?

AbiPaint is a free online image resizer. Resize photos, adjust pixels and resolution right in your browser—no Adobe installation or Canva account required.

When should I use AbiPaint?

Use AbiPaint when you need to resize or refine an image but do not have Photoshop, Illustrator, or Canva nearby.

Do I need an account?

No. AbiPaint is free, registration-free, and installation-free, so it works immediately on computers, tablets, and phones.

What else can AbiPaint do?

Beyond resizing images, AbiPaint includes brush, eraser, shape, text, and background-removal tools for students, teachers, designers, marketers, and everyday creators.

Which images work best with AbiPaint background removal?

Background removal can quickly process people, pets, objects, logos, and profile pictures. Images with simple backgrounds and clear subject contrast work best. On first use, the model is prepared in your browser. Very fine hair, whiskers, reflections, or a subject similar in color to its background may still need further cleanup.
