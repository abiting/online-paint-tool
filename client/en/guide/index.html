AbiPaint Studio Guide: Resize, Remove, Export

AbiPaint is a free browser-based editor for resizing, cropping, background removal, color adjustment, drawing, text, shapes and export. No installation or account is required.

What can AbiPaint do?

01 / CANVAS

Resize and crop images

Set a custom canvas, use common size presets, and crop imported images with direct controls.

02 / IMAGE

Adjust photos and remove backgrounds

Control exposure, contrast, saturation, vibrancy and opacity. Remove an image background and repair the mask when needed.

03 / CREATE

Add text, shapes and brush strokes

Create movable, scalable and layerable text or shapes, or draw directly with brush tools.

04 / OUTPUT

Export and save working files

Export PNG, JPG or PDF. Desktop users can retain multiple automatically saved working files.

How to use AbiPaint

1. Import an image or start with a blank canvas

Choose Import Image to begin. Your first image can define the canvas size, or you can set the width and height before creating.

2. Edit selected objects

Select an image, text, shape or brush stroke to move, resize, rotate, duplicate, delete or reorder it. Selected images can also be cropped, adjusted or cleaned with background removal.

3. Export your work

Choose PNG, JPG or PDF from Export Image. PNG is useful for transparent backgrounds, JPG for everyday sharing and PDF for documents.

Frequently asked questions

Do I need to install or sign up?

No. AbiPaint works directly in a web browser.

What kind of images work with background removal?

People, products and pets can be processed. For complex scenes or fine hair, use the keep and remove brushes after automatic removal.

Can I use AbiPaint on a phone?

Yes. The mobile workspace keeps the core canvas, import, export and object editing controls, and fits the canvas to the available workspace.

Developer: Abiting
