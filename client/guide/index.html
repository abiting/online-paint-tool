AbiPaint 使用說明：免費線上圖片尺寸修改器

AbiPaint 是免費線上圖片尺寸修改器，不用安裝 Adobe 或註冊 Canva，直接在瀏覽器調整照片尺寸、像素與解析度。

AbiPaint 可以做什麼？

01 / 尺寸

圖片尺寸修改

調整照片尺寸、像素與解析度，並可設定畫布寬度與高度。

02 / 調色

影像調色

調整曝光度、對比度、飽和度、亮麗度與不透明度。

03 / 素材

筆刷、擦布、圖形與文字

加入畫筆、圖形與文字等素材；擦布可清除筆刷內容，也能直接擦除已選取圖片的像素。

04 / 匯出

匯出影像與工作檔

匯出 PNG、JPG 或 PDF；桌面版可保留多個自動儲存的工作檔。

05 / 去背

主體去背

快速將人物、寵物、物品、Logo 或頭貼的背景改為透明。

如何使用 AbiPaint？

1. 匯入影像或設定畫布尺寸

使用「匯入影像」放入照片，或在「畫布尺寸」設定寬度與高度，再套用解析度。

2. 使用工具與素材

依需要選擇筆刷、擦布、圖形、文字、輪廓、裁切或去背；未選取圖片時，擦布可清除筆刷內容；選取圖片後，則直接擦除該圖片的像素。去背最適合背景單純的 Logo、頭貼與照片。選取素材後可移動、縮放、旋轉、複製、刪除與調整前後順序。

3. 匯出影像

從「匯出影像」選擇 PNG、JPG 或 PDF。PNG 適合保留透明背景，JPG 適合一般圖片分享，PDF 適合文件列印。

使用說明

AbiPaint 是什麼？

AbiPaint 是免費線上圖片尺寸修改器，不用安裝 Adobe 或註冊 Canva，直接在瀏覽器調整照片尺寸、像素與解析度。

什麼情況會使用 AbiPaint？

想修改圖片、照片的解析度，但手邊沒有 Photoshop、Illustrator 或 Canva 時，本工具可快速派上用場。

使用 AbiPaint 是否需要註冊帳號？

完全不需要！AbiPaint 提供免費、免註冊與免安裝的修圖服務，打開網頁即可直接使用，適合所有電腦、平板與手機用戶。

AbiPaint 還有什麼功能？

除了修改圖片尺寸，AbiPaint 也提供筆刷、擦布、圖形、文字、去背等多種功能，適合學生、教師、設計師、行銷人員等各行各業使用。

AbiPaint 的去背功能適合哪些圖片？

去背功能可快速處理人物、寵物、物品、Logo 與頭貼，背景單純、主體與背景對比清楚的圖片效果最佳。第一次使用會在瀏覽器準備模型，複雜毛髮、鬍鬚、反光或與背景顏色相近的主體仍可能需要進一步修整。
