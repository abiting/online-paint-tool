AbiPaint 使用說明：圖片尺寸、去背與修圖工作台

AbiPaint 是免安裝、免註冊的瀏覽器修圖工具。你可以在同一個工作區調整圖片尺寸、去背、裁切、調色、繪圖、加入文字與圖形，再匯出成常用格式。

開啟 AbiPaint 工作台·English guide

AbiPaint 可以做什麼？

01 / CANVAS

圖片尺寸與裁切

設定自訂畫布尺寸，使用常用尺寸範本，並以控制點裁切匯入圖片。

02 / IMAGE

影像調色與去背

調整曝光度、對比度、飽和度、亮麗度與不透明度；也可對選取圖片執行主體去背並手動修補。

03 / CREATE

文字、圖形與筆刷

加入可移動、縮放和排序的文字與圖形，或以筆刷直接創作。

04 / OUTPUT

匯出與工作檔

匯出 PNG、JPG 或 PDF；桌面版可保留多個自動儲存的工作檔。

如何使用 AbiPaint？

1. 匯入圖片或建立空白畫布

選擇「匯入影像」後，首張圖片可成為畫布尺寸基準；也可以直接設定寬度與高度，從空白畫布開始。

2. 編輯素材

選取圖片、文字、圖形或筆觸後，可拖曳移動、縮放、旋轉、複製、刪除與調整前後順序。選取圖片時也能裁切、去背與調色。

3. 匯出完成檔案

從「匯出影像」選擇 PNG、JPG 或 PDF。PNG 適合保留透明背景，JPG 適合一般圖片分享，PDF 適合文件列印。

常見問題

AbiPaint 需要安裝或註冊嗎？

不需要。工具直接在瀏覽器中執行。

去背功能適合哪些圖片？

人物、物品與寵物都可處理。複雜背景或細髮絲等案例可在去背後使用保留筆與移除筆修補遮罩。

可以在手機使用嗎？

可以。手機版保留畫布、匯入、匯出與素材編輯等核心操作，並會依可用工作區自動安排畫布視角。
