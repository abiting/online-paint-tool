# AbiPaint v1.0.0 Launches as a Free Browser-Based Photo Editing Tool for Resize, Color, Design, and Export

**Press Release / User Guide | English Edition**

When an image does not meet a submission requirement, a social post needs a new crop, or a photo only needs one line of text, opening a full-scale design application is not always the most practical answer. AbiPaint v1.0.0 is a free browser-based photo editing tool built around the tasks people need most often: resizing images, making basic visual adjustments, adding simple design elements, and exporting a finished file. No account, installation, or desktop software is required. Import an image, make the necessary changes, and export it as PNG, JPG, or PDF.

AbiPaint grew out of everyday publishing work. Abiting has operated a Detective Conan fan site for years and regularly needed to resize banners, prepare social visuals, correct image colors, and add labels to graphics. Rather than rely on a costly desktop suite or a heavier, account-based design platform for these small but frequent tasks, AbiPaint was built as a direct alternative: open a web page, place an image on the canvas, make the adjustment, and produce a usable file without breaking the flow of work.

| Core capability | What it provides |
| --- | --- |
| Canvas resizing | Direct width and height entry plus 800 × 800, 1200 × 800, and 1280 × 720 presets |
| Image editing | Importing, movement, rotation, proportional scaling, free stretching, and true crop controls |
| Image adjustments | Exposure, contrast, and saturation from -100% to 100%; opacity from 1% to 100% |
| Design tools | Three brush styles, editable text, six shape types, alignment guides, layers, and object ordering |
| Design templates | Asian and Western business card layouts with editable fields and bleed guides |
| Export and backup | PNG, JPG, PDF, browser auto-save, and portable `.abipaint` project files |

The first imported image can serve as the reference for the canvas dimensions, while later images are placed proportionally so the existing composition is not stretched unexpectedly. Users can type in exact pixel dimensions or choose a common preset. Alignment guides appear when an object approaches the canvas edge or center, making it easier to prepare avatars, website banners, cover images, and social media assets. Once an image is selected, crop mode exposes corner and edge handles; applying the crop removes pixels outside the selected area rather than merely hiding them.

AbiPaint also includes focused creation tools for fast layout work on desktop. Oil Liner, Pencil, and Ink brushes can be used for small marks or touch-ups. Users can add rectangles, circles, stars, hearts, triangles, pentagons, and editable text elements directly on the canvas. Each element can be moved, resized, rotated, and adjusted individually. Up to five layers can be used to organize a composition, and locked layers cannot be selected or moved by mistake. Forward and backward ordering, along with edge and center alignment, help keep multi-object layouts organized without requiring a separate design workspace.

The v1.0.0 release also introduces Design Templates. The Asian business card template uses a 1063 × 638 pixel canvas, while the Western business card template uses 1050 × 600 pixels. Applying either template creates a white canvas, a 3 mm bleed guide, and editable fields for a name, title, company, phone number, email address, and address. The guide is visible while editing but is not included in exported files. This gives users a reliable starting point for business card work before adding a logo, image, background, or brand colors.

For projects that need to be completed across several sessions, AbiPaint v1.0.0 adds browser-based persistence and project backups. Work is automatically saved locally in the browser and can be restored after a page refresh. On desktop, users can open up to three Working Files at once; each file keeps its own canvas, assets, layers, and adjustment settings. The File menu can export a portable `.abipaint` project file and import it again later, allowing manual backup or transfer to another device. Because clearing browser data can remove local records, important designs should still be exported regularly as project files.

The basic workflow is intentionally short. Start with **Import image**, then set the target pixel dimensions in the canvas controls. Keep exposure, contrast, and saturation at 0% for a neutral starting point, then move each control in the positive or negative direction as needed. Add text, shapes, brushes, or additional images only when the layout requires them. When the design is finished, open **Export image** and choose PNG, JPG, or PDF. If the project may need future revision, export the `.abipaint` file from **File** before producing the final image.

The mobile experience focuses on the essential tasks of importing, resizing, adjusting color, and exporting, while the desktop version provides the complete set of brush, shape, text, layer, and multi-file controls. This separation keeps the browser tool usable on smaller screens without forcing a complex desktop workflow into a mobile layout. AbiPaint is suited to students, teachers, site owners, marketers, social media editors, and anyone who needs to make a quick image-size correction without committing to a large editing suite.

AbiPaint v1.0.0 is available free of charge. It is not designed to replace advanced professional software in every situation. Its purpose is more specific: to bring the most common image tasks—resize, color, annotate, arrange, save, and export—into one lightweight browser workspace that remains easy to open, understand, and return to.

By keeping the workflow in the browser and the controls centered on common output needs, AbiPaint offers a practical middle ground between a one-time image converter and a full production design suite. The result is a tool intended for regular, repeatable visual work rather than a single narrow task.
